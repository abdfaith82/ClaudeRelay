# ClaudeRelay — Multi-agent Android app

تطبيق Android لإدارة عدة وكلاء ذكاء اصطناعي وتوزيع المهام بينهم مع التحويل التلقائي عند فشل أحد المزوّدين وحفظ نقطة الاستئناف.

## المزايا
- إضافة عدة وكلاء بأسماء ومفاتيح ونماذج مستقلة.
- دعم OpenAI API (نماذج ChatGPT عبر واجهة API)، وAnthropic Claude، وGoogle Gemini، وGroq، وOpenRouter، وMistral، وCerebras، وHugging Face.
- تخطيط المهمة إلى خطوات، ثم تنفيذ كل خطوة بواسطة أول وكيل متاح.
- التحويل إلى وكيل آخر عند حدود الاستخدام أو ازدحام الخدمة أو أخطاء الشبكة.
- تعطيل الوكيل تلقائياً عند رفض بيانات المصادقة.
- حفظ نتائج الخطوات فور اكتمالها وإمكانية الاستئناف بعد إغلاق التطبيق.

## إعداد OpenAI وClaude
1. أنشئ مفتاح API من لوحة المطور الرسمية لكل مزوّد.
2. أضف وكيلاً من نوع OpenAI أو Claude، ثم أدخل المفتاح واسم الوكيل والنموذج.
3. أضف أكثر من وكيل لتوفير بدائل تلقائية عند تعطل أحدهم.

**تنبيه:** تسجيل الدخول بحساب Google لا يصادق تلقائياً على حساب OpenAI أو Anthropic. Gemini يستخدم مفتاح Google AI Studio في هذا الإصدار. مفاتيح API والفوترة منفصلة عن اشتراكات واجهات ChatGPT وClaude الاستهلاكية.

## البناء
افتح المجلد في Android Studio مع JDK 17 ومزامنة Gradle، ثم ابنِ APK من قائمة Build.

## حماية مفاتيح API
- تُخزّن إعدادات الوكلاء الآن مشفّرة باستخدام AES-256-GCM.
- مفتاح التشفير يُنشأ ويحفظ داخل Android Keystore ولا يُكتب مع إعدادات التطبيق.
- عند أول تشغيل بعد التحديث، تُرحّل إعدادات الإصدارات القديمة من التخزين النصي إلى التخزين المشفّر ثم يُحذف المفتاح النصي القديم.
- النسخ الاحتياطي للتطبيق معطّل لتجنّب استعادة نص مشفّر على جهاز لا يملك مفتاح Keystore الأصلي.
- إذا أُعيد تثبيت التطبيق أو مُسحت بياناته فقد تحتاج إلى إضافة مفاتيح API مجدداً؛ لا توجد آلية مزامنة أو استعادة سحابية للأسرار.

## حدود الإصدار الحالي
- تنفيذ الخطوات متسلسل (خطوة واحدة في كل مرة)، وليس تنفيذاً متوازياً.
- التبديل التلقائي يعمل على مستوى طلب API عند الفشل، ولا يضمن استكمالاً مطابقاً تماماً إذا كان المزوّد قد نفّذ الطلب قبل انقطاع الاتصال.
- لا يوجد تسجيل دخول Google موحّد لمزوّدي OpenAI وAnthropic؛ لكل مزوّد آلية اعتماد مستقلة. Gemini في هذا الإصدار يستخدم مفتاح API.
- لم يُتحقق من بناء APK في بيئة التطوير هذه لعدم توفر Gradle Wrapper أو تثبيت Gradle/Android SDK.
